# FLIPNOVA sound pack (for videos)

Rendered from the game's own `js/audio.js` by `node tools/video/sound-pack.js <gameRoot>`. Sound effects only: no music, no melodies, no voice.
Mono, 44.1 kHz, 16-bit WAV, silent tail trimmed. The noise in them is random, so each render differs very slightly.
