# خريطة المهارات — مين يستخدم إيه، وإمتى

كل جلسة (الفريق اليومي، المدير، أو أنا) **لازم** تشغّل المهارة المكتوبة قبل ما تبدأ أي شغلانة من النوع ده،
وتكتب في السجل اسم المهارة اللي استخدمتها. شغل من غير المهارة المناسبة يتعتبر ناقص.

| الشغلانة | المهارات (بالترتيب) |
|---|---|
| ميزة جديدة في اللعبة | `game-feel` (الإحساس والتأثيرات) → `game-ui-ux` → `playtest-report` → `qa-plan` → `smoke-check` |
| أول دقيقة / اللاعيبة مش بترجع | `onboarding-optimization` → `retention-optimization` → `retention-churn-prevention` → `playtest-report` |
| صعوبة المراحل والتوازن (من غير ما نسهّلها) | `balance-check` → `physics-tuning` → `level-design` → `platformer` |
| مشاركة وانتشار جوه اللعبة | `referral-program` → `creator-ugc-marketing` → `in-app-events` |
| فيديو تيك توك | `marketing/TIKTOK-PLAYBOOK.md` → `marketing-skill:short-form-video` → `marketing-skills:video` → `tiktok-ads` (للأفكار بس، مفيش إعلانات من غير موافقة) |
| جدول المحتوى | `marketing-skill:content-calendar` → `social-media-strategy` → `marketing-skills:social` |
| جوجل بلاي | `app-marketing-context` → `keyword-research` → `android-aso` → `screenshot-optimization` → `ab-test-store-listing` → `app-launch` → `launch-checklist` |
| التقييمات والمراجعات | `rating-prompt-strategy` → `review-management` |
| itch.io / Steam | `itch-publish` / `steam-publish` → `game-store-page` → `steam-demo` |
| الأرقام والتقارير | `app-analytics` → `data:analyze` → `product-management:metrics-review` |
| قرار كبير | `brief` → `board-meeting` (كل مدير لوحده) → **`the-fool`** (اعتراض وتحليل قبل الفشل) → `decide` → `decision-logger` |
| خطة أسبوع/شهر | `sprint-plan` → `estimate` → `scope-check` → `gstack-plan-ceo-review` |
| مراجعة الأسبوع | `retrospective` → `gstack-retro` → `post-mortem` (للي فشل) |
| الأداء والتهنيج | `perf-profile` → `performance-optimization` |
| الأمان والغش | `security-audit` → `security-review` |
| الدخل (شكل بس) | `monetization-strategy` → `pricing-strategy` → `cfo-advisor` |
| الترجمة | `localization` → `localize` |
| مقابلة لاعيبة | `design:user-research` → `customer-support:customer-research` → `design:research-synthesis` |

## اللي لسه ناقص (ومفيش مهارة ليه)
- **تقييم فيديو قبل نشره بأرقام** (توقّع نسبة المشاهدة): مفيش مهارة موثوقة. بنعتمد على `TIKTOK-QUALITY.md` وأرقام الـ48 ساعة.
- **اختبار مغلق على جوجل بلاي (12 مختبر لمدة 14 يوم):** مفيش مهارة. الخطوات في `company/google-play-kit.md`، ومتشتريش مختبرين: لازم يكونوا ناس حقيقيين.
- **إدارة سيرفر Discord:** فيه plugin بس الاتصال بيفشل دلوقتي، فالإعداد بالإيد.
