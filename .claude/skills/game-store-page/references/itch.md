# itch.io profile

itch.io is far more freeform than Steam: no capsule template overlay, no wishlist, a
flexible page layout, and community norms that reward personality and demos. The
universal principles still hold — the specs and CTA change.

Docs: https://itch.io/docs/creators/design .

## Assets

- **Cover image:** 630×500 recommended (shown at 315×250). This is the itch equivalent
  of the capsule. Same rules apply: readable small, high contrast, name-only, no AI art,
  a border/frame helps it pop in browse grids. **No Steam template overlay to avoid.**
- **Screenshots:** minimum 7, mechanic-first, gameplay-with-UI, no menus, color variety
  (identical to universal rules). itch shows them in a simple gallery — order matters.
- **Trailer:** same structure (30-50s, cold open, 4-5 highlights in 15s, <6s shots).
  Embed via YouTube on the page; itch renders the embed inline.
- **Optional GIFs:** itch lets you embed animated GIFs directly in the description —
  genuinely animated GIFs here, not Steam's 800px-MP4 trick. Keep them small (<3 MB) so
  the page loads fast.

## Copy

- **Short "tagline"** field: genre + hook in one line. Same discipline as the Steam short
  description — genre first, verbs, no lore.
- **Description body:** no hard character cap, but *keep it tight anyway* — front-load the
  pitch in the first 1-2 sentences, then a short paragraph, then a scannable Features list.
  A long wall converts worse regardless of platform.

## CTA (no wishlist on itch)

- Pre-launch: **"Follow" the project** or collect emails — that's itch's wishlist analog.
- Demo/free build: **"Download the demo" / "Play in browser"**.
- Launch: **"Buy now" / "Download"**. End the trailer's CTA card with the matching verb —
  never "Wishlist Now" (meaningless on itch).

## Discoverability

- **Tags:** itch uses a free-tag system with a smaller effective set than Steam. Add all
  relevant genre/feature/mood tags, but itch's browse surfaces are lighter — don't expect
  Steam-style algorithmic reach. There is no 15-20 target; add what's accurate.
- **Classification:** set kind (game/tool), release status, platforms, pricing model
  (free / paid / pay-what-you-want) accurately.
- **Community:** enable the comments section and a devlog — itch's discovery is heavily
  devlog- and community-driven, so post updates.
- No Steam Developer Homepage; instead, your **itch creator page / collection** is the hub.

## Localization
Same target languages as universal if you can, but itch has no per-language store variant
— you localize the *game* and can offer a translated description manually. Lower priority
than on Steam.

## When auditing an itch page, weight these highest
Cover image readability → tagline clarity → first screenshot → trailer cold open →
Follow/Download CTA wording → devlog present.
