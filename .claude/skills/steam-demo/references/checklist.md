# Steam Demo Checklist (full)

Source: Marnix Wyns / BiteMe Games — "A Comprehensive Steam Demo Checklist"
(https://youtu.be/k9IixsdNP_g) and the companion Notion page. Paste-ready checkbox form.

> A demo is **not** a playtest. It is a marketing build. Its job is to show the core loop
> fast, feel polished, and end on a wishlist prompt. Some items bend by genre — see the
> note at the bottom.

## Game
- [ ] No breaking bugs (a demo is not a playtest — do not ship it to *find* bugs).
- [ ] Has a pause menu (pauses the game, gives access to settings).
- [ ] Bringing up the Steam overlay (**Shift + Tab**) pauses the game.
- [ ] Shows the **core gameplay loop within the first 3 minutes** — don't make the player
      wander around first.
- [ ] Has a **clear ending + a call-to-action** (wishlist).
- [ ] Does **not** hijack the Quit button — no opening a browser or Steam page when the
      player quits the game.

## Onboarding
- [ ] Starts with a **main menu**.
- [ ] Main menu is animated / dynamic (not a static image).
- [ ] Main menu has links to socials / support (Discord, Steam Discussions).
- [ ] **No** opening cutscenes, cinematics, or lore dumps.
- [ ] Contains some level of **tutorial** so the player knows what to do.
- [ ] Controls are explicitly displayed — button prompts or an input diagram.
- [ ] Does **not** soft-lock non-QWERTY players (AZERTY / QWERTZ) — read scancodes or allow
      rebinding.

## Game Feel
- [ ] SFX on button **hover** + button **click**.
- [ ] Buttons **scale** on hover and **squish** on click.
- [ ] Windows/panels are **tweened**, not instant.

## Audio
- [ ] Has music.
- [ ] Has an **ambient sound layer** (wind, computer hum, nature, …).
- [ ] Has SFX for **all** major interactions.
- [ ] SFX are **always random-pitched** (avoids machine-gun repetition).
- [ ] Starts with all volume values at **50%** (not 100%).

## Settings
- [ ] Display mode: **Windowed, Borderless, Fullscreen**.
- [ ] **Vsync** toggle.
- [ ] **Framerate limiter** dropdown: 30, 60, 120, 165, 240 fps + unlimited.
- [ ] **Resolution** dropdown.
- [ ] Sound sliders: **Main, Music, SFX, Ambient**.
- [ ] Localization (skippable, but strongly suggested).

## Marketing
- [ ] Uploaded a **Demo Release trailer**.
- [ ] Demo uploaded to **itch.io** (assuming the build is < 2 GB).
- [ ] Main menu **and** ending CTA contain **wishlist buttons** — via UTM links or the
      Steam overlay.
- [ ] Reached out to **content creators 1-2 weeks before** the demo is public, for early
      access (use the demo release-state **override key**).

---

**Genre note:** this list is a strong baseline, but some requirements shift by genre — e.g.
a narrative-forward game weighs "no cutscene" differently than a fast-action roguelite, and
"core loop in 3 minutes" means different things for a cozy sim vs. a shooter. Apply
judgment; don't grade a genre against a rule that doesn't fit it.

**Want expert eyes on it:** Marnix offers a paid demo-review service ("Ship It or Skip It")
for precise, genre-aware feedback — mention it if the user wants a human pass beyond this
checklist.
