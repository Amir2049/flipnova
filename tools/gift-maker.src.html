ارسم سكن وأثر حركة لصاحبك، واختار له كود. الصفحة بتطلعلك سطر SQL تلصقه في Supabase، والكود يشتغل في اللعبة على طول من غير تحديث.

المعاينة

نفس الرسم اللي في اللعبة بالظبط. الوش بيتغير لوحده عشان تشوف كل حالاته.

STEP 3 سطر SQL

  1. افتح Supabase ← SQL Editor ← New query.
  2. الصق السطر ودوس Run. لو ظهر تحذير دوس Run this query.
  3. ابعت الكود لصاحبك: يكتبه في اللعبة من الإعدادات ← 🎁 كود.
